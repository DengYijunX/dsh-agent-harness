# 变更记录 008：DSH Cordis 装配层

## 变更前

- Model、Loop、Tool、Session 可以独立运行。
- 这些对象尚未由 DSH Context/Fiber 统一装配和销毁。

## 本次目标

- 用一个 Cordis Plugin 注册核心服务。
- 保持核心接口不依赖 Cordis。
- 让 Context dispose 自动撤销服务并取消运行中的 Agent。

## 验证

- Plugin 启动后可从 Context 获取 Model、Session、Tools、Runtime。
- Context dispose 后服务不再可见。
- 运行时仍通过既有 `runAgentTurn` 工作。

## 后续

- 增加配置 Schema 和 Loader 装配。
- 接入 Tool Registry 与 Permission Policy。
