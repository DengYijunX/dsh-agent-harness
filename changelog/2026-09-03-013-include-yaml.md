# 变更记录 013：Include/YAML 配置启动

## 变更前

- Bootstrap 可以校验内存配置并启动 Loader。
- Harness Plugin 仍需要由调用方直接传入。

## 本次目标

- 使用 DSH Include 的 entry-list YAML 格式加载 Harness Plugin。
- 固定启动顺序为 Context → Loader → Include → Harness Plugin。
- Include 或插件失败时销毁整个 Context。

## 验证

- YAML 文件能启动 Harness 服务。
- Include 加载完成后服务可从 Context 获取。
- 关闭 Context 后插件树完整销毁。

补充：Harness Plugin 增加默认导出，满足 Include/Loader 动态模块加载约定。

## 后续

- 为 YAML entry 增加更严格的配置 Schema 和 profile/patch。
- 增加 CLI 启动入口。
