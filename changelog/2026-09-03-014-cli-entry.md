# 变更记录 014：CLI 启动入口

## 变更前

- Harness 已支持 DSH Include/YAML 启动。
- 用户仍需编写 Node 调用代码才能执行 Prompt。

## 本次目标

- 增加 `npm start` CLI 入口。
- 支持 `--config` 和 `--prompt` 参数。
- 确保正常完成和异常退出都会销毁 Context/Fiber。

## 验证

- CLI 参数解析。
- CLI 通过 YAML 启动并执行一次 Prompt。
- 帮助信息和错误退出路径。

CLI 使用 Node 22 原生 TypeScript strip-only 模式，并已移除不兼容的参数属性写法。

## 后续

- 将项目发布为带 `bin` 的 npm 包。
- 增加交互式 stdin 模式和 JSON 输出模式。
